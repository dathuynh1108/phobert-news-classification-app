# Train

Thư mục này giữ notebook Colab PhoBERT và script hỗ trợ export artifact.

Luồng đề xuất:

1. Upload repo này lên Colab hoặc mount Google Drive.
2. Đặt các file parquet vào `dataset/`.
3. Mở `train/notebooks/main_PhoBERT.ipynb`.
4. Sau khi train xong, copy artifact sang `dataset/artifacts/active/`.

Notebook được adapt từ repo gốc:

- `https://github.com/dangtai111325/VietNamNet-News-Classification/tree/main/PhoBERT`
